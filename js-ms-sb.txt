Create MYSQL running container instead of H2 database with Docker:
-----------------------------------------------------------------

docker run -p 3306:3306 --name scdb -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=scdb -d mysql
------
Exp:
 -e means : env variables
3306 - default MySQL server running port
--name dbname
MYSQL_ROOT_PASSWORD=root, username and password

-e MYSQL_DATABASE=scdb, till docker setup container, this will manage

container name : MySQL
-d detach mode
